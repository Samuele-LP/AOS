# Info
This repository contains my project for the Advanced Operating System 2025/2026 course at Politecnico Di Milano.<br>
It's a Linux kernel module that acts as a simple driver for a serial interface present on the Adafruit Neo Trinkey - SAMD21 USB Key
### Build Instructions
This project was done on a machine with a kernel compiled with Clang<br><br> Please use the <strong>make NOLLVM</strong> option if your kernel was not compiled with Clang
